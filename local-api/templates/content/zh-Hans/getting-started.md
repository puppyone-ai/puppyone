# 开始使用 puppyone

A local file workspace built for you and your agent.

这个项目就是你电脑上的一个文件夹。这篇指南是普通的 Markdown 文件：你可以编辑、改名、移动或删除它。删除后，它不会自动生成回来。

## 做一次编辑

把下面这行改成你想做的事，然后按 ⌘S（macOS）或 Ctrl+S（Windows、Linux）保存。

## 带上你的文件

把文件拖进左侧文件列表，或者通过 + 菜单新建文档。Markdown、表格及其他文件都保存在这个项目文件夹里，也可以继续用其他应用打开。

已经有文件夹或 Obsidian 知识库？直接打开它即可。Notion 内容可以先导出为 Markdown & CSV 并解压；Airtable 表格可以先导出为 CSV。打开已有文件夹不会添加这篇指南。

## 和你的 Agent 一起工作

准备好后，在 Agent 面板或设置中选择并配置 Agent。你可以请它整理笔记或处理文件，在保留它提出的修改前先检查内容。

例如：“帮我把上面的项目想法整理成一份简短计划。”

创建项目不会自动启动 Agent、执行命令或上传文件。如果你选择云端模型，发送给 Agent 的内容可能由对应模型服务商处理。本地存储并不代表 Agent 对话内容绝不会离开这台电脑。

## 把这里变成你的工作空间

需要时保留这篇指南；熟悉之后，随时换成你自己的笔记。`README.md` 留给你编写项目本身的说明。
