# Primeiros passos com o puppyone

Um espaço de trabalho com arquivos locais feito para você e seu agente.

Este projeto é uma pasta no seu computador. Este guia é um arquivo Markdown comum: você pode editar, renomear, mover ou excluir. Se ele for excluído, não será criado novamente.

## Faça sua primeira edição

Substitua a linha abaixo por algo em que você queira trabalhar e salve com ⌘S no macOS ou Ctrl+S no Windows e Linux.

Meu primeiro projeto: …

## Traga seus arquivos

Arraste arquivos para o explorador ou crie um documento pelo menu +. Arquivos Markdown, tabelas e outros conteúdos permanecem nesta pasta do projeto e continuam disponíveis para outros aplicativos.

Já tem uma pasta ou um cofre do Obsidian? Abra essa pasta diretamente como projeto. No Notion, exporte como Markdown e CSV e descompacte o arquivo; no Airtable, exporte cada tabela como CSV. Abrir uma pasta existente não adiciona este guia.

## Trabalhe com seu agente

Quando estiver pronto, escolha e configure um agente no painel Agent ou nas Configurações. Você pode pedir ajuda para organizar notas ou trabalhar em um arquivo. Revise as alterações propostas antes de mantê-las.

Por exemplo: “Ajude a transformar a ideia do meu primeiro projeto em um plano curto.”

Criar este projeto não inicia um agente, não executa comandos e não envia arquivos. Se você escolher um modelo em nuvem, o conteúdo enviado ao agente poderá ser processado pelo provedor desse modelo. O armazenamento local não significa que as conversas com o agente permanecerão sempre neste computador.

## Deixe este espaço com a sua cara

Mantenha este guia enquanto ele for útil. Substitua-o pelas suas próprias notas quando quiser. O arquivo `README.md` fica disponível para apresentar o seu projeto.
