# 开始使用 puppyone

为你和你的 Agent 打造的本地文件工作空间。

## puppyone 是什么

- **项目就是文件夹。** 这个项目就是你电脑上的一个文件夹，里面每一项都是普通文件，用其他应用也能打开。
- **每种文件都用合适的方式打开。** 写 Markdown、编辑表格、预览网页、在白板上画图，还能阅读 PDF 和 Office 文档，都在同一个地方。
- **Agent 和你处理同一批文件。** 你可以请它读取、整理或修改这里的文件，在保留它提出的修改前先检查内容。

## 用示例文件认识 puppyone

项目里放了三个示例文件，每个都用一种格式介绍 puppyone。可以从左侧文件列表打开它们。

- [Formats.csv](Formats.csv) —— 表格：puppyone 能打开哪些文件。试试加一行。
- [How It Works.html](How%20It%20Works.html) —— 网页：可以点着看的 puppyone 使用介绍。
- [Workspace Map.excalidraw](Workspace%20Map.excalidraw) —— 白板：你、Agent 和文件之间是什么关系。试试拖动一个方块。

## 和你的 Agent 一起工作

准备好后，在 Agent 面板或设置中选择并配置 Agent。你可以请它整理笔记或处理文件，在保留它提出的修改前先检查内容。

例如：“帮我把上面的项目想法整理成一份简短计划。”

创建项目不会自动启动 Agent、执行命令或上传文件。如果你选择云端模型，发送给 Agent 的内容可能由对应模型服务商处理。本地存储并不代表 Agent 对话内容绝不会离开这台电脑。

## 带上你的文件

把文件拖进左侧文件列表，或者通过 + 菜单新建文档。Markdown、表格及其他文件都保存在这个项目文件夹里，也可以继续用其他应用打开。

已经有文件夹或 Obsidian 知识库？直接打开它即可。Notion 内容可以先导出为 Markdown & CSV 并解压；Airtable 表格可以先导出为 CSV。打开已有文件夹不会添加这些示例文件。

## 把这里变成你的工作空间

需要时保留这篇指南和示例文件。它们都是普通文件，熟悉之后随时删掉即可，不会自动生成回来。`README.md` 留给你编写项目本身的说明。
