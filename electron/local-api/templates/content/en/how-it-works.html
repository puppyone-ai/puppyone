How puppyone works

Four things to know before you start.

Step 1 of 4

Your files stay in your folder

A project is a folder on your computer, and puppyone saves your work as ordinary files inside it.

  • Other apps, such as Obsidian or a code editor, can open the same files.
  • Creating a project doesn't upload anything.
  • Deleted files are not recreated.

Step 2 of 4

Every file opens the right way

puppyone picks a suitable view for each file, so you don't need a different app for every format.

  • Markdown notes with live formatting
  • CSV tables you can edit like a spreadsheet
  • Web pages, whiteboards, PDFs and Office documents

Step 3 of 4

Work with your agent

Choose and configure an agent in the agent panel or Settings. It works on the files in this project.

  • Ask it to organize notes, summarize a table or draft a document.
  • Review its proposed changes before keeping them.
  • With a cloud model, what you send may be processed by that model provider.

Step 4 of 4

Bring what you already have

Start from the files you already have instead of a blank page.

  • Drag files into the file list.
  • Open an existing folder or Obsidian vault as a project.
  • Import Notion (Markdown & CSV export) and Airtable (CSV export).
