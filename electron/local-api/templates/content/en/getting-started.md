# Getting started with puppyone

A local file workspace built for you and your agent.

## What puppyone is

- **Your projects are folders.** This project is a folder on your computer, and everything in it is a normal file. Other apps can open these files too.
- **Every file opens the right way.** Write Markdown, edit tables, preview web pages, sketch on whiteboards, and read PDFs and Office documents in one place.
- **Your agent works on the same files.** Ask it to read, organize or edit the files here, and review its proposed changes before keeping them.

## Explore with the sample files

This project comes with three sample files. Each one introduces puppyone in a different format. Open them from the file list on the left.

- [Formats.csv](Formats.csv) — a table of the files puppyone can open. Try adding a row.
- [How It Works.html](How%20It%20Works.html) — a web page you can click through to see how puppyone works.
- [Workspace Map.excalidraw](Workspace%20Map.excalidraw) — a whiteboard showing how you, your agent and your files fit together. Try dragging a box.

## Work with your agent

When you're ready, choose and configure an agent through the agent panel or Settings. You can ask it to help organize your notes or work on a file. Review its proposed changes before keeping them.

For example: “Help me turn my first project idea into a short plan.”

Creating this project does not start an agent, run a command or upload files. If you choose a cloud model, the content you send to the agent may be processed by that model provider. Local storage is not a promise that agent conversations stay on this computer.

## Bring your files

Drag files into the file explorer, or create a document with the + menu. Markdown, tables and other files stay in this project folder. You can still use them in other apps.

Already have a folder or an Obsidian vault? Open that folder as a project. For Notion, export Markdown & CSV and unzip it first; for Airtable, export your tables as CSV. Opening an existing folder doesn't add these sample files.

## Make this space yours

Keep this guide and the sample files while they help. They're ordinary files: delete them whenever you're ready, and they won't come back. `README.md` is available for your project's own introduction.
