puppyone 사용 방법

시작하기 전에 알아 두면 좋은 네 가지.

4단계 중 1단계

파일은 내 폴더에 있습니다

프로젝트는 컴퓨터에 있는 폴더이며, puppyone은 작업 내용을 그 안에 일반 파일로 저장합니다.

  • Obsidian이나 코드 편집기 같은 다른 앱에서도 같은 파일을 열 수 있습니다.
  • 프로젝트를 만들어도 아무것도 업로드되지 않습니다.
  • 삭제한 파일은 다시 생성되지 않습니다.

4단계 중 2단계

모든 파일이 알맞은 방식으로 열립니다

puppyone이 파일마다 알맞은 보기를 고르므로 형식마다 다른 앱을 쓸 필요가 없습니다.

  • 실시간 서식이 적용되는 Markdown 노트
  • 스프레드시트처럼 편집하는 CSV 표
  • 웹 페이지, 화이트보드, PDF, Office 문서

4단계 중 3단계

Agent와 함께 작업하기

Agent 패널이나 설정에서 Agent를 선택하고 구성하세요. Agent는 이 프로젝트의 파일로 작업합니다.

  • 노트 정리, 표 요약, 문서 초안 작성을 요청해 보세요.
  • 제안된 변경 사항은 적용하기 전에 검토하세요.
  • 클라우드 모델을 쓰면 보낸 내용이 해당 제공업체에서 처리될 수 있습니다.

4단계 중 4단계

이미 가진 것부터 시작하기

빈 페이지 대신 이미 가지고 있는 파일로 시작하세요.

  • 파일 목록으로 파일을 드래그하세요.
  • 기존 폴더나 Obsidian 보관함을 프로젝트로 여세요.
  • Notion(Markdown 및 CSV 내보내기)과 Airtable(CSV 내보내기)을 가져오세요.
이 페이지는 프로젝트에 있는 일반 HTML 파일입니다. 편집으로 전환하면 텍스트를 바꿀 수 있고, Agent에게 새로 디자인해 달라고 요청할 수도 있습니다.
