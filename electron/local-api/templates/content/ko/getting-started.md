# puppyone 시작하기

나와 Agent를 위한 로컬 파일 작업 공간입니다.

## puppyone이란

- **프로젝트는 폴더입니다.** 이 프로젝트는 컴퓨터에 있는 폴더이고, 안에 있는 모든 항목은 일반 파일입니다. 다른 앱에서도 열 수 있습니다.
- **모든 파일이 알맞은 방식으로 열립니다.** Markdown 작성, 표 편집, 웹 페이지 미리 보기, 화이트보드 그리기, PDF와 Office 문서 읽기를 한곳에서 할 수 있습니다.
- **Agent도 같은 파일로 작업합니다.** 이곳의 파일을 읽거나 정리하거나 편집해 달라고 요청하고, 제안된 변경 사항은 적용하기 전에 검토하세요.

## 예시 파일로 puppyone 알아보기

이 프로젝트에는 예시 파일 세 개가 들어 있습니다. 각 파일이 서로 다른 형식으로 puppyone을 소개합니다. 왼쪽 파일 목록에서 열어 보세요.

- [Formats.csv](Formats.csv) — puppyone에서 열 수 있는 파일을 정리한 표입니다. 행을 하나 추가해 보세요.
- [How It Works.html](How%20It%20Works.html) — 클릭하며 puppyone 사용법을 살펴볼 수 있는 웹 페이지입니다.
- [Workspace Map.excalidraw](Workspace%20Map.excalidraw) — 나, Agent, 파일이 어떻게 연결되는지 보여 주는 화이트보드입니다. 상자를 끌어 보세요.

## Agent와 함께 작업하기

준비가 되면 Agent 패널이나 설정에서 Agent를 선택하고 구성하세요. 노트를 정리하거나 파일 작업을 도와달라고 요청할 수 있습니다. 제안된 변경 사항은 적용하기 전에 검토하세요.

예: “첫 프로젝트 아이디어를 짧은 계획으로 정리해 줘.”

프로젝트를 만드는 것만으로 Agent가 시작되거나 명령이 실행되거나 파일이 업로드되지는 않습니다. 클라우드 모델을 선택하면 Agent에 보내는 내용이 해당 모델 제공업체에서 처리될 수 있습니다. 로컬 저장은 Agent 대화가 항상 이 컴퓨터에만 남는다는 의미가 아닙니다.

## 파일 가져오기

파일 탐색기로 파일을 드래그하거나 + 메뉴에서 문서를 만드세요. Markdown, 표 및 기타 파일은 이 프로젝트 폴더에 저장되며 다른 앱에서도 계속 사용할 수 있습니다.

이미 폴더나 Obsidian 보관함이 있나요? 해당 폴더를 프로젝트로 바로 열면 됩니다. Notion은 Markdown 및 CSV로 내보낸 뒤 압축을 풀고, Airtable은 각 테이블을 CSV로 내보내세요. 기존 폴더를 열 때는 이 예시 파일들이 추가되지 않습니다.

## 나만의 작업 공간으로 만들기

도움이 되는 동안 이 안내서와 예시 파일을 보관하세요. 모두 일반 파일이므로 준비되면 언제든 삭제할 수 있으며, 다시 생성되지 않습니다. `README.md`는 프로젝트 자체를 소개하는 용도로 사용할 수 있습니다.
