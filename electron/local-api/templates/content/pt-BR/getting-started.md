# Primeiros passos com o puppyone

Um espaço de trabalho com arquivos locais feito para você e seu agente.

## O que é o puppyone

- **Seus projetos são pastas.** Este projeto é uma pasta no seu computador, e tudo o que está nela são arquivos comuns. Outros aplicativos também podem abri-los.
- **Cada arquivo abre do jeito certo.** Escreva em Markdown, edite tabelas, visualize páginas web, desenhe em quadros brancos e leia PDFs e documentos do Office em um só lugar.
- **Seu agente trabalha nos mesmos arquivos.** Peça para ele ler, organizar ou editar os arquivos daqui e revise as alterações propostas antes de mantê-las.

## Conheça o puppyone com os arquivos de exemplo

Este projeto vem com três arquivos de exemplo. Cada um apresenta o puppyone em um formato diferente. Abra-os pela lista de arquivos à esquerda.

- [Formats.csv](Formats.csv) — uma tabela com os arquivos que o puppyone consegue abrir. Experimente adicionar uma linha.
- [How It Works.html](How%20It%20Works.html) — uma página web que você pode percorrer para ver como o puppyone funciona.
- [Workspace Map.excalidraw](Workspace%20Map.excalidraw) — um quadro branco que mostra como você, seu agente e seus arquivos se conectam. Experimente arrastar uma caixa.

## Faça sua primeira edição

Substitua a linha abaixo por algo em que você queira trabalhar e salve com ⌘S no macOS ou Ctrl+S no Windows e Linux.

Meu primeiro projeto: …

## Trabalhe com seu agente

Quando estiver pronto, escolha e configure um agente no painel Agent ou nas Configurações. Você pode pedir ajuda para organizar notas ou trabalhar em um arquivo. Revise as alterações propostas antes de mantê-las.

Por exemplo: “Ajude a transformar a ideia do meu primeiro projeto em um plano curto.”

Criar este projeto não inicia um agente, não executa comandos e não envia arquivos. Se você escolher um modelo em nuvem, o conteúdo enviado ao agente poderá ser processado pelo provedor desse modelo. O armazenamento local não significa que as conversas com o agente permanecerão sempre neste computador.

## Traga seus arquivos

Arraste arquivos para o explorador ou crie um documento pelo menu +. Arquivos Markdown, tabelas e outros conteúdos permanecem nesta pasta do projeto e continuam disponíveis para outros aplicativos.

Já tem uma pasta ou um cofre do Obsidian? Abra essa pasta diretamente como projeto. No Notion, exporte como Markdown e CSV e descompacte o arquivo; no Airtable, exporte cada tabela como CSV. Abrir uma pasta existente não adiciona estes arquivos de exemplo.

## Deixe este espaço com a sua cara

Mantenha este guia e os arquivos de exemplo enquanto forem úteis. São arquivos comuns: exclua-os quando quiser, e eles não serão criados novamente. O arquivo `README.md` fica disponível para apresentar o seu projeto.
