# Bien démarrer avec puppyone

Un espace de travail de fichiers locaux conçu pour vous et votre agent.

## Qu’est-ce que puppyone ?

- **Vos projets sont des dossiers.** Ce projet est un dossier sur votre ordinateur, et tout ce qu’il contient sont des fichiers ordinaires. D’autres applications peuvent aussi les ouvrir.
- **Chaque fichier s’ouvre comme il faut.** Rédigez en Markdown, modifiez des tableaux, prévisualisez des pages web, dessinez sur des tableaux blancs et lisez des PDF et des documents Office, au même endroit.
- **Votre agent travaille sur les mêmes fichiers.** Demandez-lui de lire, d’organiser ou de modifier les fichiers d’ici, et vérifiez les modifications proposées avant de les conserver.

## Découvrez puppyone avec les fichiers d’exemple

Ce projet contient trois fichiers d’exemple. Chacun présente puppyone dans un format différent. Ouvrez-les depuis la liste des fichiers à gauche.

- [Formats.csv](Formats.csv) — un tableau des fichiers que puppyone peut ouvrir. Essayez d’ajouter une ligne.
- [How It Works.html](How%20It%20Works.html) — une page web à parcourir pour voir comment fonctionne puppyone.
- [Workspace Map.excalidraw](Workspace%20Map.excalidraw) — un tableau blanc qui montre comment vous, votre agent et vos fichiers s’articulent. Essayez de déplacer un cadre.

## Travaillez avec votre agent

Lorsque vous êtes prêt, choisissez et configurez un agent dans le panneau Agent ou dans les réglages. Vous pouvez lui demander d’organiser vos notes ou de travailler sur un fichier. Vérifiez les modifications proposées avant de les conserver.

Par exemple : « Aide-moi à transformer l’idée de mon premier projet en un plan court. »

La création de ce projet ne démarre aucun agent, n’exécute aucune commande et ne téléverse aucun fichier. Si vous choisissez un modèle cloud, le contenu envoyé à l’agent peut être traité par le fournisseur de ce modèle. Le stockage local ne garantit pas que les conversations avec l’agent restent sur cet ordinateur.

## Ajoutez vos fichiers

Faites glisser des fichiers dans l’explorateur ou créez un document depuis le menu +. Les fichiers Markdown, les tableaux et les autres fichiers restent dans ce dossier de projet et peuvent toujours être utilisés dans d’autres applications.

Vous avez déjà un dossier ou un coffre Obsidian ? Ouvrez-le directement comme projet. Pour Notion, exportez les données en Markdown et CSV, puis décompressez-les ; pour Airtable, exportez les tables au format CSV. L’ouverture d’un dossier existant n’ajoute pas ces fichiers d’exemple.

## Appropriez-vous cet espace

Conservez ce guide et les fichiers d’exemple tant qu’ils vous sont utiles. Ce sont des fichiers ordinaires : supprimez-les quand vous le souhaitez, ils ne seront pas recréés. `README.md` reste disponible pour présenter votre projet.
