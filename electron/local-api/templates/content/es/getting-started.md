# Primeros pasos con puppyone

Un espacio de trabajo de archivos locales para ti y tu agente.

Este proyecto es una carpeta de tu ordenador. Esta guía es un archivo Markdown normal: puedes editarlo, cambiarle el nombre, moverlo o eliminarlo. Si lo eliminas, no volverá a crearse.

## Haz tu primera edición

Sustituye la línea siguiente por algo en lo que quieras trabajar y guarda con ⌘S en macOS o Ctrl+S en Windows y Linux.

Mi primer proyecto: …

## Trae tus archivos

Arrastra archivos al explorador o crea un documento desde el menú +. Los archivos Markdown, las tablas y otros contenidos permanecen en esta carpeta del proyecto y puedes seguir utilizándolos en otras aplicaciones.

¿Ya tienes una carpeta o una bóveda de Obsidian? Ábrela directamente como proyecto. Para Notion, exporta Markdown y CSV y descomprime el archivo; para Airtable, exporta las tablas como CSV. Abrir una carpeta existente no añade esta guía.

## Trabaja con tu agente

Cuando estés listo, elige y configura un agente desde el panel de Agent o desde Ajustes. Puedes pedirle que organice tus notas o que trabaje en un archivo. Revisa los cambios propuestos antes de conservarlos.

Por ejemplo: «Ayúdame a convertir la idea de mi primer proyecto en un plan breve».

Crear este proyecto no inicia un agente, no ejecuta comandos ni sube archivos. Si eliges un modelo en la nube, el proveedor del modelo puede procesar el contenido que envíes al agente. Guardar los archivos localmente no significa que las conversaciones con el agente permanezcan siempre en este ordenador.

## Haz tuyo este espacio

Conserva esta guía mientras te resulte útil. Sustitúyela por tus propias notas cuando quieras. `README.md` queda disponible para presentar tu proyecto.
