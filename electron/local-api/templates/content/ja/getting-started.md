# puppyone をはじめる

あなたと Agent のための、ローカルファイル・ワークスペースです。

## puppyone とは

- **プロジェクトはフォルダーです。** このプロジェクトはコンピューター上のフォルダーで、中身はすべて通常のファイルです。ほかのアプリからも開けます。
- **どのファイルも適した方法で開けます。** Markdown の執筆、表の編集、Web ページのプレビュー、ホワイトボードでの作図、PDF や Office 文書の閲覧が、ひとつの場所でできます。
- **Agent も同じファイルで作業します。** ここにあるファイルの読み取り、整理、編集を依頼でき、提案された変更は反映する前に確認できます。

## サンプルファイルで puppyone を知る

このプロジェクトには 3 つのサンプルファイルがあります。それぞれ別の形式で puppyone を紹介しています。左のファイル一覧から開いてください。

- [Formats.csv](Formats.csv)：puppyone で開けるファイルの一覧表。行を追加してみましょう。
- [How It Works.html](How%20It%20Works.html)：クリックしながら puppyone の使い方を見られる Web ページ。
- [Workspace Map.excalidraw](Workspace%20Map.excalidraw)：あなた、Agent、ファイルの関係を示すホワイトボード。ボックスをドラッグしてみましょう。

## Agent と作業する

準備ができたら、Agent パネルまたは設定から Agent を選び、構成します。ノートの整理やファイルの作業を依頼できます。提案された変更は、反映する前に確認してください。

例：「最初のプロジェクトのアイデアを短い計画にまとめてください。」

プロジェクトを作成しただけでは、Agent の起動、コマンドの実行、ファイルのアップロードは行われません。クラウドモデルを選んだ場合、Agent に送信した内容はそのモデルの提供元によって処理されることがあります。ローカル保存は、Agent との会話が常にこのコンピューター内だけに留まることを意味しません。

## ファイルを追加する

ファイルエクスプローラーへファイルをドラッグするか、+ メニューからドキュメントを作成します。Markdown、表、その他のファイルはこのプロジェクトフォルダーに保存され、ほかのアプリからも引き続き利用できます。

既存のフォルダーや Obsidian Vault がある場合は、そのフォルダーをそのままプロジェクトとして開けます。Notion は Markdown と CSV でエクスポートして解凍し、Airtable は各テーブルを CSV でエクスポートしてください。既存フォルダーを開いた場合、これらのサンプルファイルは追加されません。

## 自分のワークスペースにする

役に立つ間は、このガイドとサンプルファイルを残しておいてください。どれも通常のファイルなので、いつ削除してもかまいません。再作成はされません。`README.md` はプロジェクト自身の説明に利用できます。
