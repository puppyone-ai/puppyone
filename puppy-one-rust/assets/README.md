# Prototype assets

- `Geist-Regular.ttf`: generated from this repository's `public/fonts/geist/Geist-Variable.woff2`, instantiating `wght=400` and converting WOFF2 to TTF with fontTools 4.63.0. Reproduce with `python3 tools/import-font.py`. Copyright 2024 The Geist Project Authors; SIL Open Font License 1.1, included as `Geist-OFL.txt` (upstream: https://github.com/vercel/geist-font/blob/main/OFL.txt).
- `OpenSans-{Regular,Bold,Italic,BoldItalic}.ttf`: the same four static content-font instances already used by `native-editor-probe/assets`, now embedded in the main GPUI editor so rich marks use distinct real faces. Copyright 2020 The Open Sans Project Authors; SIL Open Font License 1.1 retained in `OpenSans-OFL.txt` and the packaged app. Source generation details remain in `native-editor-probe/THIRD_PARTY.md`; the files are byte-identical copies, not new font derivations.
- `icons/*.svg`: Lucide 0.562.0 geometry, the same version used by the existing Desktop. Reproduce with `node tools/import-icons.mjs /path/to/puppyone/node_modules`. Fill is none, stroke white for native tinting, nominal stroke width 1.8. These are rasterized by Rust/resvg, not a browser. ISC license included as `icons/LICENSE`.

- `icons/feedback-help.svg`: the product-owned `FeedbackHelpIcon` from `src/features/app-shell/DesktopHelpLauncher.tsx` (stroke width 1.65), written by `tools/import-icons.mjs`.
- `brand/puppy-{dark,lite}.svg`: byte-identical copies of the product's `public/assets/brand/puppy/`. `brand/puppy-dark-onboarding.svg` is `puppy-dark.svg` with the Home lockup's dark-mode CSS `filter: grayscale(1) brightness(0.7)` (`src/styles/onboarding.css`) applied to its two flat colours in sRGB (`#EDE7DE` → `#A2A2A2`, `#0E0E0E` → `#0A0A0A`), because GPUI images have no brightness filter.

- `agents/*`: the product’s existing agent identity assets, copied byte-for-byte from `public/assets/icons/agents`; `agents/chatgpt-mark.svg` wraps the unmodified `chatgpt.png` in the product's monochrome viewBox (`AgentMonochromeBrandImage`) so Codex is tinted like the Web (`python3 tools/import-agent-marks.py`); Lobe Icons MIT notice retained in `agents/lobe-icons-license.txt` and packaged as `AGENT_ICONS_LICENSE.txt`. Puppyone and provider trademarks remain with their owners.

Assets are supplied alongside source (and should be committed together) so the native build has no Node/Python prerequisite. The macOS shell may additionally load an installed system Unicode font as a fallback for filenames; that OS font is not redistributed. They keep their upstream licenses; the repository Apache-2.0 license does not override them. Existing PuppyOne brand/trademark rules still apply. No screenshots or real workspace contents are embedded in the application.
- `integrations/{github,gitlab}.svg`: byte-identical copies of the product's `public/assets/icons/integrations/` (the Import source preview on the homepage). `integrations/github-inverse.svg` is `github.svg` with the dark-scheme CSS `filter: invert(1)` (`src/styles/onboarding.css`) applied to its flat fill (`#181717` → `#E7E8E8`), because GPUI images have no filters. Third-party marks remain with their owners.
- `formats/file-formats.json`, `formats/preset-viewers.json`: the product's canonical format table (`packages/shared-ui/src/core/fileFormats.json`) and preset viewer manifest (`packages/shared-ui/src/editor/registry/presetViewerManifest.json`), re-serialised but otherwise unchanged. The native format and viewer registries read them. Reproduce or verify with `python3 tools/import-formats.py [--check]`.
