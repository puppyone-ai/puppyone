# Bien démarrer avec puppyone

Un espace de travail de fichiers locaux conçu pour vous et votre agent.

Ce projet est un dossier sur votre ordinateur. Ce guide est un fichier Markdown ordinaire : vous pouvez le modifier, le renommer, le déplacer ou le supprimer. Une fois supprimé, il ne sera pas recréé.

## Faites votre première modification

Remplacez la ligne ci-dessous par un sujet sur lequel vous souhaitez travailler, puis enregistrez avec ⌘S sous macOS ou Ctrl+S sous Windows et Linux.

Mon premier projet : …

## Ajoutez vos fichiers

Faites glisser des fichiers dans l’explorateur ou créez un document depuis le menu +. Les fichiers Markdown, les tableaux et les autres fichiers restent dans ce dossier de projet et peuvent toujours être utilisés dans d’autres applications.

Vous avez déjà un dossier ou un coffre Obsidian ? Ouvrez-le directement comme projet. Pour Notion, exportez les données en Markdown et CSV, puis décompressez-les ; pour Airtable, exportez les tables au format CSV. L’ouverture d’un dossier existant n’ajoute pas ce guide.

## Travaillez avec votre agent

Lorsque vous êtes prêt, choisissez et configurez un agent dans le panneau Agent ou dans les réglages. Vous pouvez lui demander d’organiser vos notes ou de travailler sur un fichier. Vérifiez les modifications proposées avant de les conserver.

Par exemple : « Aide-moi à transformer l’idée de mon premier projet en un plan court. »

La création de ce projet ne démarre aucun agent, n’exécute aucune commande et ne téléverse aucun fichier. Si vous choisissez un modèle cloud, le contenu envoyé à l’agent peut être traité par le fournisseur de ce modèle. Le stockage local ne garantit pas que les conversations avec l’agent restent sur cet ordinateur.

## Appropriez-vous cet espace

Conservez ce guide tant qu’il vous est utile. Remplacez-le par vos propres notes quand vous le souhaitez. `README.md` reste disponible pour présenter votre projet.
