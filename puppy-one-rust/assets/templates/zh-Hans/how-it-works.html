puppyone 怎么用

开始之前，先了解这四件事。

第 1 步，共 4 步

文件就在你的文件夹里

一个项目就是你电脑上的一个文件夹，puppyone 把你的内容保存成里面的普通文件。

  • Obsidian、代码编辑器等其他应用也能打开同样的文件。
  • 创建项目不会上传任何内容。
  • 删除的文件不会自动生成回来。

第 2 步，共 4 步

每种文件都用合适的方式打开

puppyone 会为每个文件选择合适的视图，不用为每种格式各开一个应用。

  • 边写边排版的 Markdown 笔记
  • 能像电子表格一样编辑的 CSV
  • 网页、白板、PDF 和 Office 文档

第 3 步，共 4 步

和 Agent 一起工作

在 Agent 面板或设置中选择并配置 Agent，它处理的就是这个项目里的文件。

  • 请它整理笔记、总结表格或起草文档。
  • 在保留它提出的修改前先检查内容。
  • 使用云端模型时，发送的内容可能由对应模型服务商处理。

第 4 步，共 4 步

带上已有的内容

从你已有的文件开始，而不是从一张白纸开始。

  • 把文件拖进左侧文件列表。
  • 把已有文件夹或 Obsidian 知识库直接作为项目打开。
  • 导入 Notion（导出为 Markdown & CSV）和 Airtable（导出为 CSV）的内容。
这个页面是项目里的一个普通 HTML 文件。切换到编辑就能改文字，也可以请 Agent 重新设计它。
