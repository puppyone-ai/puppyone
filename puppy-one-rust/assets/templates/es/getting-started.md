# Primeros pasos con puppyone

Un espacio de trabajo de archivos locales para ti y tu agente.

## Qué es puppyone

- **Tus proyectos son carpetas.** Este proyecto es una carpeta de tu ordenador y todo lo que contiene son archivos normales. Otras aplicaciones también pueden abrirlos.
- **Cada archivo se abre como corresponde.** Escribe en Markdown, edita tablas, previsualiza páginas web, dibuja en pizarras y lee PDF y documentos de Office en un solo lugar.
- **Tu agente trabaja con los mismos archivos.** Pídele que lea, organice o edite los archivos de aquí y revisa los cambios propuestos antes de conservarlos.

## Descubre puppyone con los archivos de ejemplo

Este proyecto incluye tres archivos de ejemplo. Cada uno presenta puppyone en un formato distinto. Ábrelos desde la lista de archivos de la izquierda.

- [Formats.csv](Formats.csv) — una tabla con los archivos que puppyone puede abrir. Prueba a añadir una fila.
- [How It Works.html](How%20It%20Works.html) — una página web que puedes recorrer para ver cómo funciona puppyone.
- [Workspace Map.excalidraw](Workspace%20Map.excalidraw) — una pizarra que muestra cómo encajáis tú, tu agente y tus archivos. Prueba a arrastrar un recuadro.

## Haz tu primera edición

Sustituye la línea siguiente por algo en lo que quieras trabajar y guarda con ⌘S en macOS o Ctrl+S en Windows y Linux.

Mi primer proyecto: …

## Trabaja con tu agente

Cuando estés listo, elige y configura un agente desde el panel de Agent o desde Ajustes. Puedes pedirle que organice tus notas o que trabaje en un archivo. Revisa los cambios propuestos antes de conservarlos.

Por ejemplo: «Ayúdame a convertir la idea de mi primer proyecto en un plan breve».

Crear este proyecto no inicia un agente, no ejecuta comandos ni sube archivos. Si eliges un modelo en la nube, el proveedor del modelo puede procesar el contenido que envíes al agente. Guardar los archivos localmente no significa que las conversaciones con el agente permanezcan siempre en este ordenador.

## Trae tus archivos

Arrastra archivos al explorador o crea un documento desde el menú +. Los archivos Markdown, las tablas y otros contenidos permanecen en esta carpeta del proyecto y puedes seguir utilizándolos en otras aplicaciones.

¿Ya tienes una carpeta o una bóveda de Obsidian? Ábrela directamente como proyecto. Para Notion, exporta Markdown y CSV y descomprime el archivo; para Airtable, exporta las tablas como CSV. Abrir una carpeta existente no añade estos archivos de ejemplo.

## Haz tuyo este espacio

Conserva esta guía y los archivos de ejemplo mientras te resulten útiles. Son archivos normales: elimínalos cuando quieras y no volverán a crearse. `README.md` queda disponible para presentar tu proyecto.
