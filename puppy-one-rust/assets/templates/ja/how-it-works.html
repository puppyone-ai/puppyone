puppyone

puppyone のしくみ

はじめる前に知っておきたい 4 つのこと。

ステップ 1 / 4

ファイルはあなたのフォルダーに

プロジェクトはコンピューター上のフォルダーで、puppyone は作業内容をその中の通常のファイルとして保存します。

  • Obsidian やコードエディターなど、ほかのアプリでも同じファイルを開けます。
  • プロジェクトを作成しても、何もアップロードされません。
  • 削除したファイルは再作成されません。

ステップ 2 / 4

どのファイルも適した方法で開く

puppyone はファイルごとに適したビューを選ぶので、形式ごとに別のアプリを使い分ける必要はありません。

  • その場で整形される Markdown ノート
  • スプレッドシートのように編集できる CSV
  • Web ページ、ホワイトボード、PDF、Office 文書

ステップ 3 / 4

Agent と作業する

Agent パネルまたは設定から Agent を選び、構成します。Agent はこのプロジェクトのファイルで作業します。

  • ノートの整理、表の要約、文書の下書きを頼めます。
  • 提案された変更は、反映する前に確認してください。
  • クラウドモデルでは、送信した内容が提供元で処理されることがあります。

ステップ 4 / 4

手持ちのファイルから始める

白紙からではなく、すでにあるファイルから始められます。

  • ファイル一覧にファイルをドラッグします。
  • 既存のフォルダーや Obsidian Vault をプロジェクトとして開きます。
  • Notion（Markdown と CSV でエクスポート）や Airtable（CSV でエクスポート）を取り込めます。
このページはプロジェクト内の通常の HTML ファイルです。編集に切り替えるとテキストを変更でき、Agent にデザインの変更を頼むこともできます。
